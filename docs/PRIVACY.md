# khshell 隐私政策

生效日期：2026-11-18

khshell（以下简称“本应用”）是一个本地运行的 SSH / SFTP / 终端客户端。本政策说明本应用会处理哪些信息、为什么处理，以及你对这些信息的控制方式。

> 发布前请把下文中的 `<开发者名称>`、`<联系邮箱>`、`<隐私政策网址>` 替换为实际信息，并确保与应用市场登记主体一致。

## 1. 我们不收集的信息

- 不收集账号、手机号、通讯录、位置、相册、设备标识符等个人信息。
- 不包含广告 SDK、统计分析 SDK 或任何遥测上报。
- 不会把你的会话配置、凭据、终端内容上传到开发者或第三方服务器。

## 2. 本机处理与存储的信息

以下数据只保存在本应用的应用沙箱内，由你自行管理：

| 数据 | 用途 | 存储方式 |
| --- | --- | --- |
| 会话配置（名称、主机、端口、用户名、分组、备注、跳板/代理设置） | 连接你指定的服务器 | 应用沙箱内 JSON |
| 登录凭据（密码 / 私钥口令） | 自动登录 | 本地加密存储（ChaCha20-Poly1305） |
| 已知主机指纹（known_hosts） | 校验服务器身份 | 应用沙箱 |
| 命令历史、快捷命令 | 命令复用 | 应用沙箱 |
| 终端输出、SFTP 浏览记录 | 界面显示 | 仅内存或应用沙箱 |
| 下载的文件 | 保存到公共下载目录或你选择的位置 | 系统文件系统 |

卸载应用会删除应用沙箱内的上述数据；公共下载目录中的文件需你自行删除。

## 3. 网络访问

本应用申请 `ohos.permission.INTERNET`，仅用于你主动发起的连接：

- SSH / SFTP / Telnet / 端口转发等直连你配置的服务器；
- 可选的会话配置同步（仅当你手动启用并填写你自己的同步地址时）。

所有连接由你发起并直接到达目标服务器，不经过开发者服务器。目标服务器如何处理数据取决于该服务器的运营方。

## 4. 文件与下载目录权限

本应用申请 `ohos.permission.READ_WRITE_DOWNLOAD_DIRECTORY`，用途仅为把 SFTP 下载的文件保存到系统公共下载目录（Download）。若你拒绝该权限，本应用会改用系统保存对话框，由你选择保存位置，其余功能不受影响。

## 5. 剪贴板

仅在你在应用内执行复制或粘贴操作时读写系统剪贴板，用于终端文本与输入框之间的复制粘贴。剪贴板内容不会被上传或持久化保存。

## 6. 第三方组件

本应用使用 Slint（界面框架）、Twemoji（彩色 emoji）、Material Icons（图标字体）、Cascadia Mono（等宽字体）等开源组件。这些组件在本地运行，不收集或上传你的数据。相关许可与署名见应用包内的 `LICENSE`、`NOTICE` 与 `THIRD_PARTY_NOTICES.md`。

## 7. 儿童

本应用面向具备服务器管理能力的用户，不面向儿童，也不会主动收集儿童个人信息。

## 8. 你的权利

- 在应用内查看、修改、删除会话与命令历史；
- 通过卸载应用清除应用沙箱内的全部数据；
- 通过系统设置随时撤销网络或文件权限。

## 9. 政策更新

本政策更新后会随应用版本发布，并在本页面更新生效日期。重大变更会在应用内提示。
